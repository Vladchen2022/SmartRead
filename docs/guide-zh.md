# SmartRead 使用指南

SmartRead 在同一个 Mac 窗口里提供英文文本阅读、音频精听和视频精学，用本机 LM Studio 查词、翻译和学语法。需要 macOS 14 或更新版本。

## 开始阅读

1. 按[首页构建说明](../README.md#从源码构建)生成 SmartRead.app，双击打开。首次打开时会看到一篇示例。
2. 在 LM Studio 的 Developer 页面启动本机服务器并加载模型。App 默认连接 `http://127.0.0.1:1234/v1`，右上角可以重新连接或选择模型。
3. 点「导入文章」（⌘I），粘贴文本、粘贴公开网页链接，或选取 `.txt`、`.md`、PDF 文件。登录或订阅后才可读的文章可以在浏览器复制正文，再粘贴到 App。
4. 单击单词先看词义，再看原句和译文。开启标题下的「点整句」后，单击句中任意位置可查看整句译文，也可以用选区旁的「朗读」。拖选后仍可翻译选区。翻译会参考前后句，右侧显示目标文字的译文。译文下的「语法解析」默认折叠，展开后先显示带颜色的主干和一处卡点，再按需「展开完整讲解」。翻译和解析选区的快捷键是 ⇧⌘T 和 ⇧⌘G。
5. 顶部滑块在 16–72 磅之间调节字号。快捷键为 ⌘=、⌘- 和 ⌘0。旁边「显示」里的「正文宽度」滑块调整左侧文字占用的宽度。左右拖动中间的分隔条，可以加宽或缩窄右侧学习助手。App 会记住最近导入的文章、字号和宽度设置。
6. 从顶部的「历史记录」（⇧⌘H）可打开以前读过的文章、删除单篇或清空旧记录。重新打开文章时会恢复上次阅读位置；顶部的「继续上一篇」可以回到最近读到一半的文章。历史或进度文件损坏时，「历史记录」会提供对应的恢复按钮，并保留损坏的原件。

点右上角齿轮或按 ⌘, 打开设置。「界面与阅读 → 主题配色」可选白色或深灰色，切换立即生效，下次打开会沿用上次的选择。首次使用默认为白色。「界面与阅读」还可以独立调整控件比例、阅读字号和两栏宽度，也可以把顶栏字号滑块移到「显示」菜单、切换单击查词或翻译整句。三个模式的倍速按钮和展开选项都跟随界面比例缩放。「听读」可以选择语音、调节遮罩和开关当前句高亮。「LM Studio」可以测试连接和选择模型。

文本、音频和视频共用右侧学习助手。点词时先看词义，再看原句和译文。开启「点整句」后，单击只显示整句翻译。音频和视频可在右上角「⋯」切换「点整句」。搭配、复制和「回到原文」等操作也在「⋯」里。文本阅读时，选中句子后可点侧栏顶部的「收藏句子」，同时保存英文原句和译文。展开语法解析后可单独收藏语法，收藏会附上英文原句。

右侧底部的「问 AI」可以就选词、原句或字幕向本机模型提问并追问。主动选词或选句会更新引用，自动播放时仍固定在原句。输入问题后按回车发送。右上角「⋯ → 问 AI」有「引用当前句」和「带上前后句」。

文本阅读、音频精听和视频学习共用「问 AI」操作。点回答里和原文一致的引文可回到出处，切回先前的句子可继续本次打开软件时的对话。「⋯ → 问 AI → 常用追问」可先编辑再发送。回答完成后可直接点「收藏回答」，把回答与该次提问引用的原句一起保存。无引用的问答可先引用原句，再重新提问后收藏。也可以在「回答操作」里点「用一下」做一道练习并获得反馈。

## 收藏和阅读反馈

- 词义、搭配和语法可在对应结果旁收藏。句子和译文共用侧栏顶部的「收藏句子」。在「本篇收藏」点「回到原句」可定位原文，并直接在右侧显示已保存的内容。再次点已收藏的按钮或列表里的「取消收藏」可取消。
- PDF 的「本书收藏」汇总所有页和章节的收藏，并标出原 PDF 页码。点「回到原句」会打开对应页面或章节。
- 在「设置 → 界面与阅读 → Obsidian 泛读收藏」选择目录后，自行导入的文本和 PDF 可自动将新收藏追加到每周一篇的 Markdown 笔记。问答收藏会把原句、问题和回答一起写在来源文章下面。按收藏日期和本地周一归周，也可手动补写本周已有收藏。更换目录时，可选择将尚未写入的收藏一同移到新目录，或保留各自原定目录。
- 读完点「完成阅读」，选择偏易、刚好或偏难，可选一个卡点并补充感受。自行导入的材料将收藏和反馈保存在 SmartRead 的应用数据中。课程文章的学习记录写入 `~/Desktop/英语精读计划/SmartRead 学习记录/<articleId>.json`。所选卡点记在可选的 `reading.difficultyReason` 字段，值为 `vocabulary`（生词多）、`phrases`（搭配难）、`longSentences`（长句难）或 `background`（背景陌生）。
- 课程 Markdown 可以带 `smartreadFormat: 1` 导入头。必填双引号字符串 `sourceId`、`title`、`readingDate`（`YYYY-MM-DD`），可加 `course`、`lesson`、`titleZh`。头部用两行 `---` 分隔，之后放英文正文。相同来源编号和正文重复导入会复用已有学习记录。
- 将 SmartRead.app 移到「应用程序」后，可运行 `open -a /Applications/SmartRead.app "/绝对路径/文章.md"`。也可经应用里的「导入文章」选文件。

## 导入 PDF

- 从「导入文章 → PDF 电子书」载入整本书。用页面上方的箭头翻页，或输入 PDF 页码后按回车跳转。应用只提取当前要打开的页，优先读取内嵌文字，扫描页使用本机 OCR。
- 默认显示英文和中文。查词、翻译、解析和听读适用于英文。打开「只读英文」可隐藏中文段落，翻页时跳过纯中文页。打开「查看原页」可核对排版、重新 OCR 整页，或按阅读顺序框选多个区域重新识别。修正结果和选框会随书保存。
- 点「按章阅读」可在同一个正文区读完一章。支持「1 Chapter」「Chapter 1」和带编号的英文章标题。跨页断开的英文句子会连起来，中文收在「本章译文」。点章号打开目录，也可以手动选起止页和跨页衔接方式。
- 每本书在历史记录里显示为一条。重新打开会恢复上次页码和页内位置，即使移动了导入时的原文件。
- 从「导入文章 → 本地文件」选 PDF。输入文件页码添加整页，或在预览里多次拖出矩形。首次框选会取代同页的整页选项。
- PDF 导入窗口可拖动边角调整大小。预览默认适合左栏宽度，可以拖动中间分隔条、点「＋」放大，或选择「适合整页」。
- SmartRead 按右侧编号逐块提取。拖动或用上下箭头排序，勾选「接到上一段」可以接回被图片或栏位拆开的文字。
- 优先读取 PDF 原有文字。扫描内容使用 Apple Vision 本机 OCR，也可以手动重识别单个部分。校对文字、检查合并预览后点「导入文章」，正文会像其他文章一样保存。

## 读难文章

- 点词后用「看整句」自动选中原句，并在右侧显示译文。「看搭配」或「看指代」会定位相关原文。
- 语法解析里可点「先看主干」。正文和右栏用相同的文字颜色、底色和短标签区分主语、主句谓语、从句和指代。
- 右侧「⋯ → 助读工具」可查看段意、背景、简单英文、原文提示和理解题。点结果可以回到对应原文。开启「跟随阅读标记难点」后，App 会随阅读位置更新本段提示。
- 短句翻译完成后可点「在原文下显示」。原文里的「收起译文」或正文标题栏里的同名按钮可以关闭该译文。

## 听读

- 普通阅读时，选中正文里的句子后按空格或点浮窗里的「试听」，就能只朗读这一句。进入听读后，空格控制播放和暂停。正文顶部的「听读」可以先选倍速，再点「朗读全文」「从这里听」或「朗读选区」。该菜单和旁边的词数跟随设置里的界面比例缩放。
- 点「朗读全文」会从首句开始，每读完一句就暂停。按 ← 或 → 逐句朗读，暂停时按空格或点播放，从下一句开始连续朗读。
- 底栏显示时，文本听读、音频精听和视频精学共用应用内快捷键。空格播放或暂停，← 上一句，→ 下一句，↓ 重听，↑ 在 0.75× 和原速之间切换。鼠标停在底栏按钮上也能查看对应按键。
- 底栏的「播放／暂停」控制连续播放。「上一句」「下一句」和「重听」各播一句，播完暂停。选区读完后，可以点「下一句」接着读正文。
- 底栏状态右侧可以选择 0.75× 或原速。文本听读会单独记住所选倍速。Kokoro 即时变速，Mac 内建语音从下一句或重听时使用新速度。
- 听读时，当前段落逐行平滑移到正文中央，再开始发声。较长的段落以正在读的句子为居中位置。顶栏「显示」里的「遮罩」可调其他段落的深浅，调到 0% 可以隐藏遮罩。
- 正在朗读的句子用黄色底色标出。逐句播放暂停后，当前句保持高亮，方便跟读。
- 三个模式下，播放器显示时双按 **↓** 或按 **M**，可记下当前句并听到一声轻响。单按 **↓** 约四分之一秒后重听。双按标记第一次按键时的句子。等下一句时可标记刚听完的句子，重复标记只留一条。音频和视频分别需要转写字幕和英文字幕，隐藏字幕后也可标记。可在「设置 → 听读 → 听力标记」关闭提示音。
- 顶栏「听力标记」按当前素材汇总，PDF 按整本书汇总。正文和字幕用红色下划线标出手动标记。点击正文中有红线的句子，可从浮窗直接「取消标记」。按重听键或点「重听」实际播出后计一次，0.75× 是其中的慢速次数。主动重听两次的句子会进入「可能卡住」，自动连播、自动循环和上下句切换不计。
- 在列表中可以按原文顺序或按重听次数复盘，直接重听、定位和收藏原句。文本原句进入「本篇收藏」或「本书收藏」，音视频原句可在「已收藏」筛选中找到。点「移出待复习」可清掉复习提示，收藏与重听记录会保存在本机。
- 默认使用 Mac 内建语音。Kokoro 也在本机运行，提供美音和英音的男女声。如果到另一台 Mac 上安装，先安装 `uv`，再运行 `bash Scripts/setup-kokoro.sh`。模型保存在用户的 SmartRead 应用支持目录。

## 音频精听

- 用主窗口顶部的学习模式菜单切换到「音频精听」。导入、历史记录、字号、宽度和底部播放器沿用文本阅读的位置。侧栏显示字幕工具。
- 将 MP3 或 MP4 拖入左侧字幕区，或点「导入音频」。媒体文件、字幕、历史和播放进度保存在 SmartRead 的应用支持目录。媒体文件缺失时，可从「音频历史」选择原文件重新关联，继续使用已校对的字幕。
- 音频导入后可以先播放，英文字幕在本机生成。字幕转写需要 macOS 26 或更新版本及支持 Apple 语音转写的 Mac。首次使用可能需要准备英语模型，MP4 按音轨播放。
- 点左侧时间或底栏的「上一句」「下一句」播放对应原声，播完暂停。「重听」回到同一句，「隐藏字幕」用于盲听。
- 底栏的倍速菜单提供 0.75× 和原速，播放时可以直接切换。
- 字幕显示时可点英文单词或拖选短语，播放会暂停，右侧显示语境释义。
- 每句旁的铅笔可以修正字幕文字和起止时间。点「音频历史」可回到之前加载的材料和进度。

## 视频精学

- 在顶部选择「视频精学」，点「导入视频」或拖入 MP4、MOV、M4V、MKV。视频按原路径播放。右侧「字幕工具」可以加载英文或中文 SRT、选择内嵌文字字幕、校时及调整句界。从视频提取内嵌文字字幕需要本机 FFmpeg，图形字幕可改用外置 SRT。
- 空格控制连续播放。← 和 → 只播目标句，↓ 重听当前句，播完暂停。字幕工具保留「先听后看」和「单句循环」。在先听后看中，⌥H 切换盲听、英文和双语，同一句从头重播，播完停住。⌥L 切换单句循环。
- 点词或拖选英文短语会暂停并在右侧查词。按 ⌥A 可用本机 LM Studio 解析当前字幕。右侧「文稿」可搜索台词并点击跳转。
- 首次启动会将已有 AEVP 历史复制到 SmartRead 的视频库，包括原文件位置、播放进度、倍速和字幕设置。原 AEVP 可继续使用。视频精学设置可选择 Obsidian 目录，只有在结果中确认才写入新笔记。
